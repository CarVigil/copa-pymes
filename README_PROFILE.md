## 📊 Proyectos Destacados

### 🏆 Copa Pymes - Sistema de Gestión de Torneos
Sistema completo Full Stack para la gestión de torneos deportivos con:
- **Backend:** Node.js, Express, TypeScript, MikroORM, MySQL
- **Frontend:** React 19, TypeScript, Context API, React Router
- **Características:**
  - 👥 Sistema de autenticación y roles (Admin, Gestor, Árbitro, Recepcionista, Jugador)
  - 🏟️ Gestión de torneos, divisiones, equipos y sedes
  - 📅 Administración de partidos e inscripciones
  - 🏅 Sistema de premios y clasificaciones
  - 🔐 Seguridad con JWT y encriptación de contraseñas
